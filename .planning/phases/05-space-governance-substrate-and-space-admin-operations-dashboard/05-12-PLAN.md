`CapabilityManifest.tsx` — props `{ granted: readonly Capability[] }`. It maps over `CAPABILITIES` imported from the domain module, never over a locally re-typed list, so adding a capability adds a manifest row automatically. Each row is a mono line: the Hebrew label from `CAPABILITY_LABELS_HE` plus `✓ מוענק` or `✕ לא מוענק`. The glyphs are `aria-hidden`; the meaning lives in the adjacent Hebrew word, because a glyph-only indicator is not accessible. Render as a `<dl>` or a `<ul>`, not a table — this is a list, not tabular data.

Below the rows, the note in mono `--np-ink-faint`: `הרשאות נבדקות בשרת בכל פעולה. פעולה שלא הוענקה לכם פשוט לא מוצגת בלוח — היא לא מוסתרת מאחורי כפתור כבוי.`

`EscalationDialog.tsx` — a client component wrapping `ConfirmDialog` with `kind="audited"` and this copy:
- heading `פנייה למנהל־על`
- body `הפנייה נשלחת למנהלי הפלטפורמה יחד עם שם המרחב ועם החשבון שלכם.`
- field label `מה תרצו לבקש? (חובה)` — this overrides `ConfirmDialog`'s default `נימוק ההחלטה (חובה)`, because the field is a request rather than a decision reason
- field error `נדרש תיאור — לפחות 10 תווים.` — likewise overriding `נדרש נימוק — לפחות 10 תווים.`
- placeholder `תארו מה חסם אתכם — למשל הרשאה שאתם צריכים, או השעיה שנראית לכם שגויה.`
- confirm `שלחו פנייה`
- success announcement via `aria-live="polite"`: `הפנייה נשלחה. מנהל־על יקבל אותה עם פרטי המרחב.`

It POSTs to `/api/space-admin/{spaceId}/escalations`. It is deliberately **not** a `mailto:` — that leaves no server-side record, and an escalation about a wrongly-suspended admin is exactly the case that needs one. Put that sentence in the component docblock.

This is the one control on the dashboard rendered regardless of capability, including to a suspended admin and to an admin holding nothing at all. Otherwise the people who most need it are the people who cannot reach it. State that in the docblock too, so a later "consistency" pass does not gate it.

Do **not** edit `apps/web/src/components/space-admin/index.ts` in this plan. Plans 05-12 through 05-15 run in the same or an adjacent wave and would collide on that one file. `page.tsx` is a Server Component. It awaits `params`, reads the session, and calls `getSpaceOverview` — the **same use-case the API route calls**. It must not import from `@/lib/supabase/db` or `@/server/infra/**` directly; a page is directly addressable and runs with full server privileges, so its authorization has to come from the same place the API's does.

On `FORBIDDEN` it renders `NoPermissionPanel` plus `EscalationDialog` inside the shell, and renders **no** `SpaceAdminHeader` — an admin who holds nothing must not learn the space's name from the page they were refused. On `UNAUTHORIZED` it redirects to sign-in.

On success it renders, in order:
1. `SpaceAdminHeader` with the space name, type label, slug, `shortId`, today's date, and the suspension flag.
2. `SpaceAdminNav` with `visibleHrefs` derived from `capabilities` — a surface the admin lacks has no link. Overview itself is always linked.
3. A `<section aria-labelledby>` per panel, `h2` at `--text-base`/800 preceded by a kicker and a `--np-rule-heavy`.
4. The standfirst, one paragraph in `--np-font-body` at `--text-base`, max two lines.
5. The four figures, each rendered **only if its value is not null**: `הצעות ממתינות להכרעה`, `חברים במרחב`, `הצבעות פעילות`, `התראות שנשלחו החודש`. A null figure is absent, never `0` and never `—`. Figures are Heebo 900 at `--text-3xl` with `font-variant-numeric: tabular-nums`, in a non-interactive card with no hover rule.
6. The decision-queue panel: heading `דורש הכרעה`, up to five rows with a `StatusChip`, and the CTA `לכל ההצעות ←` linking to `/proposals`. Empty state text: `אין כרגע הצעות שממתינות להכרעה.` Rendered only when `recentQueue` is not null.
7. `CapabilityManifest` with the granted list.
8. The escalation panel: kicker `■ הסלמה · ESCALATION`, body `נתקלתם במשהו שחורג מההרשאות שלכם, או במקרה שדורש מנהל־על?`, and the `פנייה למנהל־על` CTA opening `EscalationDialog`.

Responsive, per the contract: below 768px a single column with `h1` at `--text-2xl` and box padding `--space-4`; 768–1023px puts the figures in a 2×2 grid; at 1024px and above the overview splits with the decision queue at the inline start and the manifest plus escalation at the inline end, figures in one row of four, box padding `--space-6`. Breakpoints are pixel literals in `@media` — the only permitted hardcoded length, matching `apps/web/src/app/[locale]/dashboard/page.module.css`.

`loading.tsx` — the shell-boot spinner: `--space-10` square, `--np-rule-heavy` border, `--np-red` top edge, `animation: spin 0.9s steps(8) infinite` (mechanical, not smooth), `animation: none` under `prefers-reduced-motion`, with the copy `…טוען את לוח הניהול`. Never a spinner and skeletons at the same time — the per-panel skeletons live inside the page, this is only the boot state.
