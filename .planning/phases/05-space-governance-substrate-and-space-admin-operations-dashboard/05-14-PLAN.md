A Server Component calling `getSpaceMetrics`. The whole design of this surface is about not implying a drill-down the API will refuse.

**On the deliberately small scope.** Four aggregate cards and a footer note is the entire surface, and that is the specification, not a shortfall. CONTEXT.md defers the richer statistics dashboard to issue #91; what SPACE-07 requires here is a surface that proves the aggregates-only promise — no per-resident row, no drill-down, no export — and four honest figures do that. A reviewer comparing this against #91 should read the gap as scope discipline. Adding a breakdown, a filter, or a time series here would not be a bonus; it would be the thing this surface exists to refuse.

**Forbidden on this surface, exhaustively:** clickable stat cards, any `<a>` or `<button>` wrapping a figure, a hover state on a figure, a chevron or `←` glyph on a card, a `צפו בפירוט` affordance, any per-resident row, any name, any identity field, any map pin, any export control. There must be no `:hover` rule on `.statCard` at all, and `cursor: default`.

**Rendering rules, one per status:**
- `available` with a value → the number, Heebo 900 at `--text-3xl`, `font-variant-numeric: tabular-nums`, in a plain `<span>` inside a non-interactive card. A genuine zero renders `0`.
- `suppressed` → the literal string `<5` in mono, with `מוסתר — קבוצה קטנה מדי` beneath it at `--text-sm` in `--np-ink-faint`. The client never receives the true small number — the API already replaced it — so render what arrived and never invent a fallback zero.
- `unavailable` → `—` with `הנתון לא זמין`. Never `0`.

Four cards: `תושבים רשומים במרחב`, `משתתפים פעילים (30 יום)`, `הצעות שהוגשו`, `שיעור השתתפות`.

If bars are used they are `TallyBar` with a red fill on a `--np-paper-2` track, and each always carries its numeric value in mono beside it — never a bar alone.

The footer note is always present, in `--np-font-body` at `--text-base`: `כל המספרים כאן מצטברים. אין בלוח הזה פילוח או צפייה ברמת תושב יחיד — לא במסך ולא ב־API שמאחוריו.`

States: skeleton cards while loading; `EmptyPanel` with `אין עדיין מספיק נתונים` / `המספרים יופיעו כאן אחרי ההצבעות הראשונות במרחב.`; `ErrorPanel` on failure; `NoPermissionPanel` without `metrics.read`.

Responsive: one column below 768px, 2×2 at 768–1023px, a row of four at 1024px and above.
  </action>
