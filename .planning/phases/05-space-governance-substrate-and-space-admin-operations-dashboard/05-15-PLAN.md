| 7 | `send_failed` | `role="alert"` panel, composer content preserved | back to state 1; the preview must be recomputed |

State 0 is the one place where absence and Rule B agree: the send control is *absent*, not disabled, because an exhausted quota is not self-resolvable within the session.

**Staleness.** Any change to the title, body or audience selector transitions 3 → 4 **immediately on change, not on blur**. The client holds the server-issued `previewToken` from the preview response and sends it with the send request; the server rejects a token that does not match the current payload. The UI never computes the audience itself — it has no list of user ids and must not acquire one.

The send is the surface's single page-primary action and the only red `lg` button on the dashboard, which is why its label may be `--text-lg`: 19.2px at weight 800 clears WCAG's large-text threshold, the sole reason a red fill at 4.03:1 is permitted for it.

**Error mapping.** A 409 whose message is the audience string returns the composer to state 4 with that banner; a 409 whose message is the content string does the same with the content banner; a 429 switches the composer to state 0; anything else is state 7 with the send-error copy. Never lose the typed title and body.

**Table.** `PressTable` with six columns. Always visible: when, action, reason. Hidden below 768px: actor, object, and the prior→new state — as matched `data-col` pairs, reachable through the row disclosure `הצג פרטים ▾`. The caption is the Surface 6 caption.
