<objective>
Ship AUTH-01 end to end on the server: a resident submits an organization claim with evidence, a
super-admin reviews it in a queue, and approval — and only approval — turns the organization into
the verified official municipality while granting the claimant `authority_admin`.

Purpose: ROADMAP success criterion 1. "Verification is a super-admin decision with recorded
evidence, actor, timestamp, and reason; it is never automatic." Plan 08-01 made an
undocumented verified row unrepresentable in the database; this plan makes the only code path that
produces one go through `requireRole(actor, 'super_admin', null)`.

Output: two use-case modules, four API routes, one test file.
</objective>

export async function POST(request: NextRequest) {
  const session = await getSessionFromRequest(request);
  if (!session) return respond(errAsync(unauthorized()));
  const limit = await someLimiter.check(session.userId);
  if (limit.limited) return createRateLimitResponse(limit) as NextResponse;
  const body = await request.json().catch(() => null);
  const parsed = parse(SomeRequestSchema, body);
  if (parsed.isErr()) return respond(errAsync(parsed.error));
  return respond(someUseCase(session.userId, parsed.value));
}
